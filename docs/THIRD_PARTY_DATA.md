# Third-party resources

This repository reports experiments that used third-party resources but does not redistribute their restricted or complete source content.

| Resource | Role | Included here | Obtain from |
|---|---|---|---|
| AI Hub Public Complaint Counseling data | SFT source data | Dataset identity and protocol only | AI Hub dataset 71852 |
| AI Hub Private Complaint Counseling data | SFT source data | Dataset identity and protocol only | AI Hub dataset 71844 |
| Qwen/Qwen3-8B | Base model | Revision and inference metadata only | Hugging Face model repository |
| BAAI/bge-m3 | Retriever v2 | Frozen result metadata only | Hugging Face model repository |
| BAAI/bge-reranker-v2-m3 | Retriever v2 reranker | Frozen result metadata only | Hugging Face model repository |
| Nine official Korean school-administration sources | RAG corpus | Titles, issuers, URLs, chunk IDs, locators, and hashes | URLs in `data/retrieval/source_manifest.json` |

Researchers must review and comply with the current terms of each source. The repository's Apache-2.0 and CC BY 4.0 licenses do not override third-party terms.
