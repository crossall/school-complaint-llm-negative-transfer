# v1.0.0 release notes

This archival release accompanies the manuscript **“Target-Task Misalignment in LLM Domain Adaptation: Multi-Seed Negative Transfer and Retrieval Failures in School Complaint Response.”**

It contains:

- SCB-48 and its frozen evaluation keys;
- compact outputs from the primary SFT, Public multi-seed, and RAG experiments;
- anonymized expert ratings and adjudicated Experiment 2 safety flags;
- Retriever v1 metadata/audits and frozen Retriever v2 results;
- CPU-only scripts that reproduce the manuscript analyses;
- the format-compliant-only Public multi-seed sensitivity analysis and regression test;
- citation, license, provenance, and DOI-deposition metadata.

AI Hub source data, processed training files, model weights, QLoRA adapters, full official-document text, and direct rater identifiers are excluded.
